

This project has been organized to keep the files clean, structured, and easy to maintain.

## 📁 Folder Structure

### `test/`

All HTML files that were created and used for **testing, experimenting, and learning how to push projects to GitHub** have been moved into this folder.

These files are kept for reference and testing purposes and are not part of the main application.

### `images/`

**All images used throughout the entire application** should be placed in this folder.

If an image is used anywhere in the project, it should be stored inside `images/` rather than scattered across different folders.

### `css/`

All CSS files used to style the application should be placed in this folder.

### `pages/`

All new HTML pages for the main application should be placed in this folder.

### `js/`

All JavaScript files used for the application's functionality should be placed in this folder.

Please place new files in their appropriate folders instead of leaving them in the project root.
